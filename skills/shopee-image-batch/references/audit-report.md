# 品質、追溯與離線報告

## 狀態

- PASS：全部適用必要條件實測通過，無未解內容／視覺疑點。
- REVIEW：有完整成果／作業稿但仍有必要資訊矛盾、來源缺漏、接縫、繁中、可讀性、容量或張數衝突。M依規則精簡且必要資訊齊全時，正常省略本身不構成REVIEW。
- FAIL：必要來源缺失／損壞、必要階段未完成、必要輸出未產生。
- N/A：僅使用者確認類別不適用，記確認依據，不掩蓋未完成。

商品／模式／整批取最嚴重適用狀態。機器稽核與視覺驗證分欄；沒檢視不能空白當通過。

M詳情與MOMO封面預設各自「未啟用」，不列為缺件、不要求使用者確認N/A；只有明確要求對應項目時才納入必要產出、流程與報告驗收。

## 驗證

先依 [分割前視覺驗收](pre-slice-review.md) 驗收整理稿，全部通過才開始S／M；以下是必要的切片後驗證，不能用來取代或延後前置關卡。來源變更須重新驗收。

1. 檔案實際解碼、RGB、尺寸、bytes、命名、順序、來源SHA-256及映射。
2. 每個還原接縫商品／文字連續，無重複線、白黑線、背景色差、遺失、誤刪重疊和缺口。
3. OCR有視覺或人工校正，台灣繁中／術語正確，數值／型號／單位相符，無簡體宣傳殘影、文字重疊和新增不透明蓋字，跨接縫文句完整。
4. 商品外觀／比例／顏色／結構／配件／LOGO一致，無虛構零件或修縫局部重畫。
5. S自然切割、來源完整覆蓋及內容保留；固定寬1000，實際寬÷高0.5～32（含邊界，整數高度32～2000），最多12張，每張≤2,000,000 bytes。
6. 僅啟用M時，核對M唯一來源及模式。MOMO編輯版檢查1–20頁、每頁1000×1500、必要資訊逐項覆蓋、受保護值與條件、取捨理由、圖文區域映射、編輯稿重新驗收及JPEG一致性；重組對象是M編輯頁，不是未刪減3版。完整固定模式核對固定Y區間、全量覆蓋、預期／實際片數與無損重組；超限全稿只放第6資料夾。
7. 有浮水印時依 [主圖浮水印分套](watermarks.md) 逐套核對約定範圍、素材、樣張決定、位置、遮擋、檔名對應與主圖規格；確認無浮水印主圖仍保留，各套不合併計算張數。

## 資料夾

未指定輸出位置時，本次版本位於 `來源目錄/輸出/YYYYMMDD-v01/`；僅M重跑依啟動規則選基準目錄。日期採使用者時區，同日版本遞增，不覆寫。多商品批次在本次版本內按商品分目錄；所有成品、草稿、提示詞、紀錄及報告集中保存在本次版本：
- 0_處理紀錄/work/存放其他中間檔；0_處理紀錄/保存原始接縫分析、接縫前後對照、原始還原作業資料、背景修復、OCR及文字紀錄；有啟用M時才另存本次M中間來源及歷史M版本。
- 預設1_主圖、適用的2_選項圖、3_詳情頁、4_S詳情頁；明確要求M詳情時才建立5_M詳情頁。MOMO封面同樣僅明確要求時由封面技能另製，不因有M詳情就連帶生成。
- 6_待人工審核/接縫異常、文字異常、圖片異常、超限完整稿。
- 有浮水印時另有 7_浮水印主圖/套別/；0_處理紀錄/保存浮水印素材、樣張及浮水印紀錄.json。未啟用不要求此類別，不需另問 N/A。
- M版來源：只有使用者自行準備時存在，不自動建立。
- 預覽總覽.jpg、處理報告.html、文字轉換對照.csv、圖片來源對應.csv。

整批總報告以相對路徑連各商品。僅M模式註明其他模式未執行。

5版只放符合數量、尺寸及容量的候選。M超限或容量不符時，整套JPEG只放第6資料夾，5版不另留副本；已有3版或5版的相同檔案，異常清單以相對路徑／雜湊引用，不再複製。無損中間稿只放處理紀錄，用途與正式JPEG區分。審核資料夾保留實際異常及取捨證據，不把正常省略素材都複製進來。

## 紀錄契約

JSON及CSV用UTF-8；CSV建議BOM方便試算表。機器座標半開區間、左上原點，標座標空間及寬高。多來源／重排映射拆多列，不以一個檔名冒充追溯。

來源清單：
source_id, product, category, sku, relative_path, width, height, bytes, sha256, natural_order, decode_status

文字轉換對照.csv：
text_id, product, source_ids, source_boxes, original_text, zh_tw_text, confidence, correction_evidence, protected_values, repair_method, image_edit_call_id, final_boxes, status, reason

圖片來源對應.csv：
output_path, output_sha256, source_id, source_sha256, source_box, normalized_box, output_box, scale_x, scale_y, overlap_removed_px, change_type, evidence_path, status

change_type區分原始保留／去重／去字／補景／文字重排／裁切／縮放。AI與新排文字屬衍生像素，記原區域和操作，不謊稱原始像素。無法得知原文／信心／審核者時不捏造。

MOMO編輯版另保存`M必要資訊覆蓋.csv`及`M內容取捨.csv`，逐項記ID、資訊類別、是否必要、保留/整併/省略、原因、來源區域、原文/摘要、最終文案及成品頁碼。圖文重排可拆多列來源映射；`M計畫.json`、兩份CSV及最終頁面雜湊綁定於`M切片紀錄.json`。程式只能核對紀錄、數值字串與版本，不會自動理解圖片或判斷漏列必要資訊。

接縫：
upper_source, lower_source, type, evidence, cuts_product, cuts_text, merged, overlap_px, normalized_overlap_px, restored_y, source_transforms, before_preview, after_preview, status, reason

每一邊界一列，切商品／文字用是／否／不確定；重疊高度區分來源與規格化座標。

模型每次實際呼叫記工具／可得模型、時間、call_id、輸入來源、遮罩座標、採用區域及驗證；重試也計次。沒用明記0，不捏造模型版本。

## HTML

UTF-8、lang=zh-Hant、viewport、內嵌CSS、手機／電腦可讀、無CDN／遠端字型／網路。圖片與連結用有效相對路徑，所有檔名／OCR／文案做HTML escape，不成可執行JS。實際本機開啟測連結和圖片。

必含：
- 日期、商品／批次狀態、模式、完成與缺失階段。
- 來源數量／路徑／雜湊／分類，原圖成品對照，各張尺寸／實際bytes／順序／檢查。
- 文字對照、補景方式、實體簡體保留揭露、模型實際次數／區域、商品SKU一致性。
- 獨立列出「分割前視覺驗收」：逐張圖片版本／SHA-256、字體排版／去字殘影／背景陰影／商品保真四項結果、整圖及100%局部檢視證據、問題區域、修正前後對照與複檢結論；未通過時寫明S／M尚未執行及阻擋原因，不只展示最後切片。
- 獨立章節「原始詳情頁切割與還原分析」：原圖數、參與連續接圖來源圖數（去重計）、獨立設計圖數、異常邊界數、成功還原數、重疊去重數、未確認／無法還原數。圖數與邊界數分清。
- 每個異常接縫上／下圖、類型、是否切商品／文字、是否還原、實際重疊px、狀態／方式、前後圖、合併座標、新切線與原因。
- S合併來源、切線與結果。
- 僅啟用M時列M來源、輸出模式、實際來源清單與3版差異。編輯版列出必要資訊的來源與成品頁碼、各內容取捨理由、編輯前後頁數、逐頁規格、新舊稿驗收及壓縮後實際核對。完整固定模式另列來源規格化前後總高、去重／留白量、長圖總高、新增留白量（固定模式必須0）、每片Y、預期／實際片數及超限原因。無3版可比記N/A，不假設相同；未啟用M僅註明「未啟用」，不要求M清單、預覽或紀錄。
- 全部REVIEW／FAIL明細、影響、對應檔與後續建議，不隱藏失敗商品。
- 有浮水印時增加分套預覽、無浮水印主圖與素材對應、實際位置／縮放／透明度、樣張決定、檢查及待確認事項；不能只展示其中一套就宣稱全部完成。

超限完整稿只放6_待人工審核/超限完整稿，保留全部內容；無可用正式候選時明確說明，不把超限或來源矛盾稿稱為可直接上架。工具JSON／CSV不能取代完整HTML。若環境無法以瀏覽器開啟本機報告，照實記錄可執行的靜態連結／圖片檢核及未完成的互動／響應式測試，不虛填網頁視覺PASS。
