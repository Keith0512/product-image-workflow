# 來源、接縫與台灣繁中處理

## 掃描與排序

僅讀授權資料夾的JPG／JPEG／PNG／WEBP。按商品、分類、有效SKU建立清單，檔名自然數字排序，1、2、10依序，不依檔案系統列舉順序。排序不明、缺檔、低解析度或分類疑點記REVIEW；不同商品／SKU不混用。

一般掃描排除來源內所有「輸出」子樹、「0_處理紀錄」「1_主圖」「2_選項圖」「3_詳情頁」「4_S詳情頁」「5_M詳情頁」「6_待人工審核」「7_浮水印主圖」「浮水印」「浮水印素材」「M版來源」、本次輸出與歷史版本。其他位置的指定浮水印另用 `--exclude` 排除並記錄，不當商品圖。歷史目錄依已知路徑、版本清單、報告及結構辨識，不以任意商品名稱的字母／數字猜測。僅M重跑依獨立來源規則。

記錄商品、SKU、分類、來源路徑、尺寸、bytes、SHA-256、排序及異常。有效SKU由使用者資料、檔名及畫面交叉確認，不僅依圖片張數。主圖超過9張額外保留待選，不刪除。

## 每一相鄰邊界

檢視上圖底部、下圖頂部和完整上下文，必要時製作接縫對照。

- 商品：輪廓、顏色、紋理、角度及結構能否接續？是否被截斷／缺零件？
- 文字／表格：半行文字、殘缺字元、數值及單位、框線、表格列、箭頭是否跨圖？
- 背景：場景、地面、天空、陰影、漸層及紋理是否連續？是否重疊／缺漏？
- 設計：是否獨立卡片、不同場景或刻意分段？不能只憑底色相同合併。

| 類型 | 證據與處理 |
|---|---|
| CONTINUOUS | 確認同一畫面直接連續，按原順序接續 |
| OVERLAP | 可比對重複內容，算出並核對重疊高度後去重 |
| INDEPENDENT | 獨立完整設計，保留分段 |
| MISSING | 疑似缺口，不補造，保留並REVIEW |
| UNCERTAIN | 證據不足，保留並REVIEW |

每個邊界都記錄。空白／單色的匹配須再有商品、文字、紋理或版面證據，避免誤刪合法內容。

## 原始還原

1. 使用未修改原檔、確認順序及分類。
2. 無重疊直接接續；只移除確認重複區域，不猜刪文字或商品。
3. 保存來源在作業圖的座標、保留／去重區、變換矩陣或比例及對齊原因。
4. 不裁商品美化接縫，不加大片空白掩蓋，不用AI補零件，不靠商品變形對齊。
5. 寬度不同先辨識匯出、邊框、留白、排版、縮放／裁切差異。確認連續才可保比例轉換共同作業寬度；必要時以背景對齊，記錄縮放、補邊及裁切，不強拉商品。
6. 驗證輪廓連續、無缺口、扭曲、雙重內容、白黑線或背景斷層。原始資料足夠才稱「已完整還原」。

可用分塊、磁碟中介或記憶體映射處理長圖，但維持同一邏輯長圖及座標。作業塊保留足夠上下文，避免OCR／補景再次被切斷。分析、對照與還原資料只放0_處理紀錄。

## OCR與校正

連續畫面先還原才OCR，不把來源切線當句尾。記錄原文、台灣繁中、來源座標、信心與校正依據。跨接縫句子／表格以完整區域辨識，對照兩張原圖和OCR修正誤字；不各翻半句再拼接。

逐項核對品牌、型號、SKU、數量、尺寸、重量、電池容量、電壓、單位、認證和安全警示；不直接採未校正OCR。辨不清的數值保留並REVIEW，不推測。簡繁轉換器只是輔助，不等於台灣用語／數值驗證。

## 去字補景及繁中排版

- 純色背景以一致背景修復，不留矩形邊界。
- 照片、漸層、紋理建立緊貼字形／描邊的遮罩；傳統修復不足時使用可用IMAGE編輯工具，保護商品和實體標示。
- 只合成允許的背景區域，即使模型傳回整張圖，遮罩外仍保留原像素；遮罩不得侵入商品、LOGO和真實印刷。
- 背景乾淨才用可控文字工具排繁體。保留原風格、相近字級／字重／字距／行距／顏色、對齊和閱讀順序；透明底白字照舊。
- 不新增黑、灰、白或其他不透明矩形蓋字；原有標籤、表格底色和資訊框可保留。
- 可不改資訊地調換行／段距／版面以利手機閱讀；不可縮長圖使小字難讀。
- 真實簡體印刷保留並揭露。「斤」等市場單位不明保留來源並REVIEW。未確認促銷、保固和功能承諾不新增或改寫。

## 主圖、選項與3版

主圖／選項保比例，以自然背景擴展成1000×1000；商品、接頭、配件、LOGO及必要資訊不能裁掉。AI只擴背景，商品保留來源。逐項核對選項款式、顏色、SKU。首張突出商品，不新增促銷。跨圖疑點先查誤分類，不直接合照片。

3版還原、繁中化後保比例規格化寬1000，再選特色之間、段落／照片結束後、表格下方、步驟之間、設計留白自然分段。避商品中央、人臉／身體重點、字行、數值和單位之間、表格列、安全警示、同一步驟重要圖文。無安全切線保留較長完整段，不為原始圖數硬切。

只移除確認無資訊的留白；保護淡色內容、表格線、步驟、圖片細節和安全警示。重新分段後以座標覆蓋確認全部應保留內容都有去向。
