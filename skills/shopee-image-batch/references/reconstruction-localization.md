# 來源、接縫與台灣繁中處理

來源分組、接縫還原與OCR校正適用兩種製作模式。以下保留原版布局的處理預設用於原風格繁中；明確要求重設計時，完成完整資訊盤點後依[共用重設計規則](../../product-image-workflow/references/redesign.md)編排，不必先產生原風格定稿。商品保真、來源只讀、事實核對與後續驗收均維持。

## 掃描與排序

僅讀授權資料夾的JPG／JPEG／PNG／WEBP。按商品、分類、有效SKU建立清單，檔名自然數字排序，1、2、10依序，不依檔案系統列舉順序。排序不明、缺檔、低解析度或分類疑點記REVIEW；不同商品／SKU不混用。

一般掃描排除來源內所有「輸出」子樹、「0_處理紀錄」「1_主圖」「2_選項圖」「3_詳情頁」「4_S詳情頁」「5_M詳情頁」「6_待人工審核」「7_浮水印主圖」「8_MOMO專用」「浮水印」「浮水印素材」「M版來源」、本次輸出與歷史版本。其他位置的指定浮水印另用 `--exclude` 排除並記錄，不當商品圖。歷史目錄依已知路徑、版本清單、報告及結構辨識，不以任意商品名稱的字母／數字猜測。僅M重跑依獨立來源規則。

記錄商品、SKU、分類、來源路徑、尺寸、bytes、SHA-256、排序及異常。有效SKU由使用者資料、檔名及畫面交叉確認，不僅依圖片張數。主圖超過9張額外保留待選，不刪除。

## 每一相鄰邊界

檢視上圖底部、下圖頂部和完整上下文，必要時製作接縫對照。

- 商品：輪廓、顏色、紋理、角度及結構能否接續？是否被截斷／缺零件？
- 文字／表格：半行文字、殘缺字元、數值及單位、框線、表格列、箭頭是否跨圖？
- 背景：場景、地面、天空、陰影、漸層及紋理是否連續？是否重疊／缺漏？
- 設計：是否獨立卡片、不同場景或刻意分段？不能只憑底色相同合併。

| 類型 | 證據與處理 |
|---|---|
| CONTINUOUS | 確認同一畫面直接連續，按原順序接續 |
| OVERLAP | 可比對重複內容，算出並核對重疊高度後去重 |
| INDEPENDENT | 獨立完整設計，保留分段 |
| MISSING | 疑似缺口，不補造，保留並REVIEW |
| UNCERTAIN | 證據不足，保留並REVIEW |

每個邊界都記錄。空白／單色的匹配須再有商品、文字、紋理或版面證據，避免誤刪合法內容。

## 原始還原

1. 使用未修改原檔、確認順序及分類。
2. 無重疊直接接續；只移除確認重複區域，不猜刪文字或商品。
3. 保存來源在作業圖的座標、保留／去重區、變換矩陣或比例及對齊原因。
4. 不裁商品美化接縫，不加大片空白掩蓋，不用AI補零件，不靠商品變形對齊。
5. 寬度不同先辨識匯出、邊框、留白、排版、縮放／裁切差異。確認連續且不改相對位置及構圖時，才可保比例轉換共同作業寬度。原風格不靠補邊、擴圖、裁切構圖或移動元素來對齊；無法無損還原時保留分段及原幾何並標 REVIEW，記錄尺寸及理由。
6. 驗證輪廓連續、無缺口、扭曲、雙重內容、白黑線或背景斷層。原始資料足夠才稱「已完整還原」。

可用分塊、磁碟中介或記憶體映射處理長圖，但維持同一邏輯長圖及座標。作業塊保留足夠上下文，避免OCR／補景再次被切斷。分析、對照與還原資料只放0_處理紀錄。

## OCR與校正

連續畫面先還原才OCR，不把來源切線當句尾。記錄原文、台灣繁中、來源座標、信心與校正依據。跨接縫句子／表格以完整區域辨識，對照兩張原圖和OCR修正誤字；不各翻半句再拼接。

逐項核對品牌、型號、SKU、數量、尺寸、重量、電池容量、電壓、單位、認證和安全警示；不直接採未校正OCR。辨不清的數值保留並REVIEW，不推測。簡繁轉換器只是輔助，不等於台灣用語／數值驗證。

## 去字補景及繁中排版

本節的原風格版面限制適用原位換字。非方形主圖及選項圖需要交付1:1時，按下一節的方形轉製分支處理。

- 純色背景以一致背景修復，不留矩形邊界。
- 照片、漸層、紋理建立緊貼字形／描邊的遮罩；傳統修復不足時使用可用IMAGE編輯工具，保護商品和實體標示。
- 原風格只在原文字區內修補舊字、描邊及投影遮住的底圖。即使模型回傳整張圖，只取舊字修復遮罩內的像素，換字也限於原文字區。圖框、圖案、商品、LOGO、真實印刷和遮罩外背景保留原樣。重設計的新情境另依共用規則選參考圖編輯或原商品區域合成，逐項核對商品。
- 原風格用可控工具在原位置、原文字框內換成台灣繁中。維持原對齊、行分配、字級、字重、字距、行距、色彩、描邊／投影及層級；原字型沒有繁體字形時，使用外觀相符的繁中字型。無字或已是繁中的區域不改。重設計先策劃整體畫面，短文案可由生圖工具原生設計並逐字驗收；密集數字、規格及必要條件用精確排字。
- 不新增黑、灰、白或其他不透明矩形掩蓋未清除的舊字；原有標籤、表格底色和資訊框可保留，重設計的新資訊框須排在乾淨底圖上。
- 繁中文句若放不下，先找意思等同、條件與數字完整且能放回原框的寫法。仍放不下或無法保留文字樣式時，保留原幾何稿並標 REVIEW，記錄原文、擬用譯文及區域。不得移動文字、改框大小、換行、調字級或用新圖文布局來容納。
- 真實簡體印刷保留並揭露。「斤」等市場單位不明保留來源並REVIEW。未確認促銷、保固和功能承諾不新增或改寫。

## 主圖、選項與3版

原風格主圖（含原封面）及選項圖按原順序輸出。方形來源在原位換字，再保比例縮放至1000×1000。需要交付1:1的非方形來源，先讀[原風格方形轉製](../../product-image-workflow/references/square-original.md)，以逐張原圖作版面、風格及商品參考，交給AI工具直接製作完整方形畫面。以同一圖文配置微調必要間距、留白及等比大小，避免只延展四邊、補邊、硬裁或拉伸。逐項核對選項款式、顏色及SKU，有歸類疑點先核實來源。明確指定原比例交付時原位換字，按指定比例驗收。仍需方形而無法轉製時，保留原位換字後的原比例候選於待審區並記明原因。

重設計主圖按情境與購買理由製作大主視覺，選項圖以SKU及內含辨識為主，依共用規則選製作方式並核對商品；3版按各頁任務交替情境、細節、操作及規格，以內容對照核對完整實質資訊。以下原圖接續的座標覆蓋用於原始還原及原風格處理；重設計另以每項資訊與各商品來源區域對應新布局，不要求新布局維持原圖的連續Y座標。

3版還原、繁中化後，可保比例規格化寬1000，保持版面幾何，再選特色之間、段落／照片結束後、表格下方、步驟之間、設計留白作技術切線。避商品中央、人臉／身體重點、字行、數值和單位之間、表格列、安全警示、同一步驟重要圖文。無安全切線保留較長完整段，不為原始圖數硬切。

原風格保留原有留白及完整畫面。僅可按證據移除原匯出切片間重複的重疊像素，並依原順序接合／分割，不移動或刪減任何原版元素。重新分段後以座標覆蓋確認原順序與所有內容都有去向。

主圖、適用選項圖及3版整理好後，先執行 [分割前視覺驗收](pre-slice-review.md)，逐張檢查字體排版、去字殘影、補景多餘陰影與商品保真。通過前不得開始S／M合併、切片或壓縮；修正後複檢並綁定新圖雜湊。
