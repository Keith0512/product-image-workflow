# S／M輸出規則

## S：相鄰合併與語意安全切割

唯一來源本次3_詳情頁，依自然順序相鄰合併。寬1000、高500–32,000、最多12張、單張≤2,000,000 bytes。

這是已繁中內容的上架整合，與原始還原分開記錄。接近高度／容量上限先找附近自然段、完整照片或商品結束處；不切字行、表格列、安全警示和重要步驟。末段不足500時與前段重分組，不加大片空白。

先改分組再高品質JPEG最佳化，不無限制降品質或寬度。可在不漏內容下重排。無法兼顧張數、容量、尺寸、清晰度與完整性，保留完整稿並REVIEW，明確區分正式候選與超限稿。

## M唯一來源

完整流程預設本次3_詳情頁；有明確指定來源時尊重指示，不自行讀舊成果。

重跑／更新／重新生成M依序：
1. 使用者明確來源路徑優先，作唯一來源。
2. 否則讀指定成果根目錄、與3版同層的M版來源。
3. 僅該資料夾完全不存在才回退同根3_詳情頁。
4. M版來源存在但空、不是資料夾、圖片損壞或全無效，停止並REVIEW／FAIL，不回退。部分損壞也不可默默略過。
5. 不自動建M版來源，不加回已移除的圖，不跨版本／商品／SKU補圖。
6. 禁止4_S和舊5_M來源；若使用者本次明確改變這項契約，先說明再按新指示執行。

只讀選定資料夾內自然排序的有效圖片，記清單及雜湊；子目錄若有圖片，先解決歸屬與順序，不偷偷遞迴混入。

## M來源接縫

檢查商品接續、重複、文字／表格截斷、缺圖、繁中完整性及SKU。只在本次0_處理紀錄/本次M中間來源副本還原確認接續／去重，原來源與3版不改。缺失不從別處補回；疑點REVIEW。

每個相鄰邊界都記證據，類型同完整批次。重疊高度記於來源及規格化兩個座標空間，無重疊不裁。寬度保比例規格化1000並記映射。

## M固定切片

全部內容以寬1000、零額外間隔垂直串接為邏輯完整長圖。不可先各切來源再給不足片補白，不因來源邊界加分隔帶。

設高H，預期片數ceil(H/1500)。人讀含尾端座標：第n片X=0…999，Y=1500(n−1)…min(1500n,H)−1。機器紀錄用半開區間[y0,y1)，標示清楚。

末片保留剩餘高度，不補滿。商品可跨片，只要接回完整、無漏、無重複、無新增空白、無位移、無扭曲。若要求每張不可切商品，明確改成另定自適應安全切割，不能冒充固定1500。

切線穿字元則REVIEW。最終長圖前可微調段距／文字位置／換行，不能刪內容、加大片空白、隱藏增高、變形或犧牲可讀性；不能兼顧則保留完整切片揭露。

H>30,000先查有證據重複、非必要留白及閱讀無損排版，再重算。不得刪規格、教學、安全警示和重要圖片。仍>20片則整套REVIEW，保留完整長圖與全部審核片，記超限原因；不能只交前20片。

逐片≤500,000 bytes，建議450,000–480,000，優先高品質JPEG最佳化、移除多餘中繼資料，不降1000寬。壓縮後查小字、紋理、表格和數值；容量過關但模糊REVIEW。

## 色彩、壓縮與重組

RGB JPG優先，必要時RGB PNG。處理EXIF方向、透明合成和ICC色彩，不直接丟棄色彩設定使商品變色。透明圖轉RGB需合理背景，不能變黑。

保存無損作業稿，按切片座標應能精確重建「規格化後作業長圖」。去重、縮放、重排須由映射追溯，不謊稱最終像素等同原圖。JPEG有損，以覆蓋、接縫和視覺差異驗證，不要求逐像素一致。
