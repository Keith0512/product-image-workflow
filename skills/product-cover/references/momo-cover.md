# MOMO 專用版與 YCbCr 檢核

只有使用者明確要求 MOMO 封面／專用圖或 MOMO 整套，且由「商品繁中」入口交接啟用該版，或單獨要求本版時讀取。預設不生成本版，不因使用者要求M詳情就連帶啟用。本版與高資訊量封面分開製作、分開驗收，不做二選一。

## 版面與商品

- 無壓標、無壓框、無浮水印。不另外疊加品名、賣點、價格、活動貼紙、獨立店家／品牌 Logo、功能特寫框或裝飾邊框；商品實體原有的文字與 Logo 保留，不為「無壓標」抹掉真實印刷。
- 使用純色背景，預設依商品對比選白色或其他合適純色；不使用情境、漸層或紋理。純白背景本身不等於白邊，禁止的是額外補出的白／黑邊條或框線。
- 販售商品占圖片至少 80%，同時完整呈現商品，不拉伸比例、不裁掉零件、不用未販售道具或文字湊占比。確認單品／套裝及款式，不把未核實的配件、贈品放入畫面。
- 在實際成品上記錄占比的判讀依據及完整檢視證據。官方頁面沒有公布像素計算法；商品外接框可作構圖參考，但不能把外接框面積或單邊長度當成已證明商品實體占比。狹長、鏤空等商品若無法可靠確認，同時保留完整商品並標 REVIEW，不虛填 80%。
- 輸出 1000 × 1000 JPG，不可有白／黑邊。容量依下列來源的 50–1000 KB；本套件以十進位 50,000–1,000,000 bytes 記錄，實作優先落在 60,000–1,000,000 bytes 以避開 KB 換算邊界。不能透過改小尺寸、加雜訊或附加無關資料湊容量；無法兼顧時保留清楚稿並 REVIEW。
- 無浮水印成品存為本次版本的 `8_MOMO專用/主圖_01.jpg`。不納入 `1_主圖` 的一般主圖排序，也不納入 `7_浮水印主圖` 的任何套別。

## JPEG 的實際 YCbCr type

MOMO 主圖及廣告圖均須檢核最終檔的 YCbCr 編碼。若本版同一個檔案供兩種用途，記錄兩種用途及同一檔案的驗證證據；高資訊量版不因此視為 MOMO 合格。

- RGB 是編輯／解碼後的顯示模式，YCbCr 是此處須確認的 JPEG 編碼色彩表示；兩者並不衝突。`Image.open(...).mode == "RGB"`、sRGB ICC、`.jpg` 副檔名、三個色彩分量或 YCbCrSubSampling 標籤單獨存在，都不足以證明合格。
- 使用支援的編碼器輸出 YCbCr JPEG。例如 Pillow／libjpeg 預設將 RGB 轉為 YCbCr 後儲存；不要啟用 `keep_rgb=True`。先正確處理來源色彩描述與透明底，再編碼，不只改副檔名或寫一個宣稱 YCbCr 的中繼資料。
- 對實際最後交付檔使用下列唯讀工具，或能提供等效 JPEG 編碼證據的工具。工具會核對可解碼性、尺寸、容量、方向與 JPEG 的 JFIF／Adobe transform／SOF 分量識別等資訊，排除實際 RGB、CMYK、灰階或無法判定的檔案。無法判定時重新以已知編碼流程輸出並再驗證，不猜 PASS。

```text
python scripts/check_momo_jpeg.py 本次版本/8_MOMO專用/主圖_01.jpg --out 本次版本/0_處理紀錄/MOMO編碼檢核.json
```

路徑以本技能資料夾為準；可傳多個實際主圖／廣告圖逐檔檢核，`--out` 只建立新檔。需要 Python 與 Pillow，缺依賴時使用環境提供的相容執行器或專案專用環境，不修改共用 Python。

`FILE_OK` 僅代表機械條件符合，整體仍為 REVIEW，直到代理實際完成無壓標／框／浮水印、純色背景、商品占比、無白黑邊及商品保真驗收。報告保存最終檔路徑、SHA-256、實際 bytes、編碼標記證據、工具及視覺結果。改尺寸、壓縮、轉檔或重新存檔後，對新檔重新檢核並更新雜湊；批次工具的一般 RGB 稽核不代替這項檢查。未檢核、證據不明或仍有疑點時不得宣稱 MOMO 版已 PASS，也不宣稱已被平台接受。

## 官方依據與適用範圍

- [MOMO 商店規則中心：如何在 momo 發布商品](https://rules.momo.com.tw/goods/00021/)，查核日期 2026-11-03。商品頁特色填寫的「商品主圖上傳」及「廣告用圖」均要求 YCbCr 檢核；廣告用圖另列無壓標／框／浮水印、純色背景、商品占比、尺寸與容量。
- 本技能依使用者要求，讓 MOMO 專用版統一採上述廣告用圖的版面限制。一般 MOMO 主圖的 Logo／浮水印條款與廣告圖不同，不將本版限制誤稱為所有 MOMO 圖片的一律規定。其他分類、版位或更新規範須查對應官方來源，不擴大成自動上架授權。
- [Pillow 官方 JPEG 儲存選項](https://pillow.readthedocs.io/en/stable/handbook/image-file-formats.html#jpeg)：RGB 轉 YCbCr 的預設行為及 `keep_rgb` 選項。此為編碼依據，不是平台規範。
