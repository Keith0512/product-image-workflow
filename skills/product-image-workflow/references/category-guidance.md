# 商品情境指引

商品以戶外為主，兼顧旅遊與潮流3C。先從實際用途、買家及素材選擇情境；可依商品結合兩類重點，不為類別拆成新技能。重設計時用本指引安排視覺與內容；原風格繁中只用來理解術語及檢查必要資訊，不據此改掉原版風格。

| 商品情境 | 能說明使用利益的畫面 | 優先講清楚的內容 |
|---|---|---|
| 露營生活：帳篷、桌椅、寢具、炊具 | 營地草地、山景或林間的實際起居／休息／用餐；帳篷用門廳活動、內帳看景與站坐尺度，桌椅用坐姿與桌面操作。大情境承接嚮往，功能頁換結構與動作 | 展開／收納尺寸、容納與配置、搭設、標配與選配、材質及來源中的耐候／使用限制 |
| 登山徒步與輕量裝備 | 實際攜行位置、收納與展開對照、扣具操作及材質特寫，讓便攜有視覺依據 | 重量、體積、承重與條件、操作及適用環境；重量不能只靠視覺暗示 |
| 戶外機能、照明及電力 | 營地桌面照明、掛燈動作或已確認的設備連接，交替全景、控制與接頭特寫；暗景保留輪廓，光型及性能以來源為準 | 亮度／功率／容量及量測條件、續航條件、介面、防護與操作限制；依實際商品選用 |
| 旅遊與通勤 | 實際放進哪個包、如何取用、移動或桌邊操作，搭配攜帶狀態及尺寸 | 尺寸、收納、攜帶方式、操作便利及適用範圍；登機或各地可用等說法須有對應依據 |
| 潮流3C及隨身配件 | 實際桌面／通勤／露營操作搭配商品攝影；用接口近照、連接關係、控制動作或收納狀態證明賣點，材質以局部光影呈現 | 型號、接口、相容性、供電、實際功能與套裝內容；裝飾效果不能暗示未證實性能 |

## 跨類別與品牌一致

- 戶外電源可用露營情境，加上3C的介面、供電與條件說明；旅行充電器可用行李／隨身情境，加上相容性與實際規格。不為套分類而移除另一類的重要資訊。
- 優先沿用本次提供或明確指定的品牌識別、字體層級與版面原則，再依商品調整情境和點色。只有商品品牌Logo時，不自行發明店家品牌。
- 戶外不預設一律森林、軍綠、黑底或焚火；旅遊不預設一律機場；3C不預設一律霓虹。參考圖片、商品顏色、材質、實際使用限制及手機可讀性共同決定方向。
- 色調及背景光線可建立一致氛圍，商品顏色與材質仍依真實來源。實拍、功能特寫與規格表可採不同版面，保持同套字體、間距與識別即可。
