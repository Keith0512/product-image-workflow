# 原風格的方形轉製

原風格繁中的封面、主圖或選項圖原稿不是 1:1，且本次交付要求方形時，採用本流程。已是方形的圖與詳情圖依原本的原位換字規則。本次若明確要求保留原比例、原像素、原構圖位置完全不動或禁止生圖，依指定限制處理。1:1 轉製沿用原風格模式、原順序及原圖角色。

1. **先看原稿。** 確認商品及 SKU，記下主體角度、圖文分區與閱讀順序、品牌元素、背景及色調，核對需要換成台灣繁中的文案、規格數值與單位。沒有文案的原圖維持無文案。
2. **以原稿為參考直接生成 1:1。** 使用可接受參考圖的 AI 生圖／編輯工具，優先內建 `image_gen`。傳入該張原稿作為版面、視覺風格與商品參考。盡量保留商品在原有一側、標題和次要資訊的相對位置、對齊及層級。只在方形範圍內微調留白、元素大小和間距，讓商品輪廓完整、文字可讀。避免將原圖置中後單純延展四邊或補大面積背景。保護商品結構、角度、顏色、材質、配件及實體 Logo／印刷，不拉伸、不裁掉重要內容、不新增景物、賣點或宣傳框。
3. **逐張對照後輸出。** 對照原稿確認圖文關係、配色、背景及商品身份，檢查圖像無變形、款式與配件無誤，並以手機縮圖檢查商品是否突出、畫面是否平衡。繁中文案、標點、型號、數值及單位逐字核對。必要時用可控工具修正在同一圖文區內的字，保留原有文字層級。確認生成圖實際為正方形，再等比例輸出至交付尺寸，預設為 1000 × 1000。依子技能規格複檢格式、檔案容量及壓縮後的小字。
4. **留下出處與驗收。** 記錄原稿路徑、原尺寸、實際工具及對照結果，標記為「原風格方形轉製」。原素材保留。仍需方形而工具不可用、使用者限制或重試後仍無法通過保真與規格驗收時，保留已核對的原比例候選，在待審區列出具體原因。尺寸待審與視覺驗收分開，通過視覺驗收的詳情仍可繼續製作 S 及已啟用的 M。
