# 主圖／詳情頁差異預覽

## 每個商品一頁

每個商品產出一個 `商品名稱_主圖詳情頁差異預覽.html`，集中在本次版本目錄，例如 `輸出/20261117-v02/`。同批商品名稱有重複時在名稱後加已知的型號或款式以區分。兩套都在本次製作時，等該商品兩套成果完成後合併到同一頁。處理報告與整批總報告連到各商品的比較頁，最終交付也提供連結。

頁面提供「原圖」「原風格繁中」「繁中重設計」的勾選項。任選兩項左右比較，順序固定為原圖、原風格、重設計。預設原圖和原風格，只有重設計時預設原圖和重設計。還沒有成果的選項顯示不可用。切換主圖與詳情頁時沿用選擇，若某個版本沒有該分類就顯示缺項。兩欄各自保留圖片順序、張數、捲動、跳圖、適寬及 100% 檢視。欄首顯示版本資訊，待審候選清楚標示。

- 完整製作的主圖用各版本的完整主圖，詳情用完整3版。原風格按原序呈現首圖及一般主圖，待審候選在頁面和報告中標明。原風格另製的高資訊量封面由報告獨立連結。
- 只做封面列主圖，分類識別用 `cover`，使用原封面或原首圖與本次封面。只做批次列本次適用分類。僅M重跑用已確認的唯一來源及最終M版或完整待審候選，分類識別用 `m-detail`，和完整3版的 `detail` 分開。選項、浮水印與 MOMO 專用封面只在本次有適用成品且需比較時列入。
- 原圖使用本次核對的來源原檔。原圖中的舊活動及其他差異保留，修正依據記在報告。

## 自動帶入同商品的歷史成果

本次已完成的模式優先。缺少其中一套時，在同一輸出父目錄依版本從近到遠查找更早的 `YYYYMMDD-vNN`，用 `product_id` 精確比對商品、版本與 SKU。只帶入當時實際製作、圖稿驗收通過、檔案雜湊一致，且至少有本次一個相容分類的最近成果。歷史稿只供預覽，頁面與報告標明來源版本。找不到符合的成果時，仍交付可以比較的項目。

舊版成果若只有原圖與重製圖的舊索引，先沿同一輸出父目錄查找最近的商品報告，核對型號、版本、SKU、製作模式、圖稿通過紀錄及成品或快照雜湊。只有確認相符時，才在本次計畫填入該歷史模式圖檔、`status: "PASS"` 和實際 `version`。已驗收的舊索引及原有報告保留，前次預覽頁中的借用稿不視為前次新製作的成果。用商品名稱、資料夾名稱或模式名稱單獨比對皆不足以確認。

## 產生方式

先由本次盤點確認商品識別及圖片角色，依每套成品的實際順序準備計畫。圖片路徑可相對於計畫檔，也可使用絕對路徑。每個分類的 `id` 唯一，不適用的分類省略。作品通過圖稿驗收後用 `PASS`，已有完整待審候選時用 `REVIEW`。

```json
{
  "title": "折疊露營椅 ABC-01",
  "product_id": "品牌/ABC-01/商品版本一/黑色款",
  "variants": {
    "original": {"status": "PASS"},
    "localized": {"status": "PASS"}
  },
  "groups": [
    {
      "id": "main",
      "label": "主圖",
      "original": ["原始主圖01.jpg", "原始主圖02.jpg"],
      "localized": ["繁中主圖01.jpg", "繁中主圖02.jpg"]
    },
    {
      "id": "detail",
      "label": "詳情頁",
      "original": ["原始詳情01.jpg", "原始詳情02.jpg"],
      "localized": ["完整3版詳情01.jpg"]
    }
  ]
}
```

重設計的鍵是 `redesigned`。本次製作的模式省略 `version`，由工具使用本次輸出版本。經核實而明確填入的舊版模式使用實際來源版本。用整批共用的本次版本目錄作為每次 `--output`，即使該商品的計畫與成品位於該目錄的子資料夾。

```bash
python scripts/build_compare_preview.py --plan /path/to/商品計畫.json --output /path/to/輸出/YYYYMMDD-v02
```

工具預先檢查圖片，並使用內嵌 CSS／JavaScript 和相對路徑產出離線頁面。素材副本與索引分別按商品保存在版本根目錄的 `0_處理紀錄/差異預覽素材/` 與 `0_處理紀錄/差異預覽索引/`。搬移時保留整份版本目錄。重新出預覽時使用新版本目錄，可沿用已驗收的圖片並標明實際來源版本。

## 驗收

1. 核對本次版本根目錄只有每商品一個新比較頁。用索引核對每個版本的商品、來源版本、圖片、順序及 SHA-256。報告連到該商品的比較頁，並記錄已帶入的歷史版本及待審候選。
2. 用瀏覽器開啟。查預設兩欄、可用的勾選組合、主圖與詳情切換、缺項說明、各欄來源版本及待審標示。確認圖片可載入，原尺寸可開啟。桌面與窄螢幕均應保有可操作的兩欄。
3. 分別捲動、跳圖及切換縮放，核對另一欄的位置及縮放。切回同分類及同版本時，核對先前位置。將實測結果寫入報告。工具產出索引的 `NOT_VERIFIED_BY_TOOL` 只表示可供瀏覽器驗收。
