# 繁中重設計

使用者明確要求「繁中重設計」「重新設計情境／賣點圖」「重新編排整套」時使用。以原廠圖文核實商品與外觀，從買家情境重新策劃畫面、賣點證據及繁中排版；驗收包含商業視覺品質，翻譯正確與尺寸合格不足以判定完成。

未指定仍走原風格繁中；只提供參考網址、只要求翻譯或M輸出不自動切換。沿用本次範圍、來源只讀、新版本及S／M交付約定，不另造腳本mode。僅封面不擴成整套；僅M重跑沿用唯一來源規則；MOMO專用封面的純色、無壓標等限制仍優先。

重設計在逐圖企劃時讀[露營與3C合格／退稿範例](redesign-examples.md)的相關案例；建立共同美術方向後、寫提示詞前讀[共用提示詞與整套視覺一致性](redesign-prompts.md)。兩份文件保留方法來源、固定GitHub版本與核對日期；採用其設計方法，不新增外部技能或生圖服務依賴。

## 1. 先拆解原廠素材

完成商品／SKU分組、必要接縫還原與OCR校正，把下列內容寫入兩個子技能共用的「商品製作摘要.md」。不必先產生另一套原風格定稿。

- 商品事實：型號、版本、顏色、規格與條件、標配／選配／贈品、操作及限制。沿用已確認答案，解決影響定稿的矛盾；不能把別色、別款、原廠活動或其他套組移入本SKU。
- 素材角色：區分商品身份、實際使用、功能特寫、尺寸／結構、配件與純風格參考；記錄可用角度及清晰度。先找能解釋商品的照片與局部，不急著把每張原廠海報去字後重排。
- 購買理由：依「來源事實 → 買家何時遇到什麼問題 → 合理使用利益 → 用什麼畫面說明」推導。每個主賣點指向資料與畫面證據；情境氛圍不能當作性能實測，未知數值不猜。
- 可製作與缺口：區分直接有依據、須保留條件、無法證明的說法。字型、構圖及選材可自行判斷；產品事實不以設計假設補造。

明確要求重設計情境圖，已包含本次範圍內合理的新構圖、背景與非販售情境道具，不再逐張追問是否允許新背景。使用者指定「只用原照」「不可生圖」「只改封面背景」等時依其限制；未指定製圖方法不等於禁止使用可用生圖工具。背景授權不代表可以改造商品。

## 2. 逐張規劃使用情境與畫面證據

摘要列簡短逐圖表：圖號／角色｜獨立曝光或連續詳情及序列位置｜買家問題｜單一主張｜來源事實與商品照片｜主要畫面及動作｜景別／構圖｜前後承接與品牌露出｜定稿文案｜製作方式。頁數依實際內容及通路容量決定，不固定張數、不為湊數重複畫面。

每張的主張、利益與證據需連得起來；原廠只提供構造而未證明結果時，使用中性功能描述。首張允許疊字時，主標需能辨識商品品類，情緒標語放次要層；不能只靠副文案小字讓買家猜商品。

| 圖片角色 | 畫面任務 |
|---|---|
| 封面／第一主圖 | 立即辨識販售商品與主要購買理由。大商品或實際使用情境承擔主視覺；品名、利益及必要版本條件有清楚層級。「高資訊量」集中於有用資訊，不把全部規格塞進首圖。 |
| 情境圖 | 說明誰在何處、如何使用、為何方便或嚮往。商品與人物、地面、空間、道具的關係可信，商品保持主角。只把去背商品貼在森林前、看不出使用關係時，重新策劃構圖。 |
| 賣點／功能圖 | 以真實細節、實際動作、局部放大或已核實示意解釋一個功能。收納呈現收納狀態與尺寸，接口展示正確接頭；不能全套只重複商品全貌換標題。 |
| 規格／操作／標配 | 清楚交代數字、條件、步驟及實際收到的內容，用表格、圖解與真實配件照片。沒有結構資料就不生成剖面、爆炸圖或未見視角。 |
| 選項圖 | 辨識可購SKU、顏色、版本及內含，突出商品輪廓與差異。可用乾淨背景及同套識別，不必照搬封面情境或塞完整詳情；單一SKU也要清楚標出販售版本。 |

依[商品情境指引](category-guidance.md)挑場景與畫面證據。整套交替全貌、使用、特寫與規格；角度及使用狀態只採來源能確認的範圍，不要求每張都有人物、森林、圖示列或同一框架。

本技能的台灣蝦皮直式詳情採由上往下連續閱讀的完整敘事。品牌Logo與完整品名集中在首屏，尾屏視需要再出現一次；中段不新增重複的品牌頁首／頁尾或獨立海報式開場。主題標題可保留，但應短而承接前文，依內容調整大小，無須每段都用同樣大的開場。主圖與選項圖是獨立曝光，可各自保留品牌與品名；商品照片上的實體印刷Logo仍須保留。

連續感來自字體、色調、照片、間距與閱讀節奏，並檢查相鄰切片的主題及上下留白是否順接。每張提示詞仍可獨立執行，但詳情成品要承接整套敘事；不要求做連續跨圖拼接風景，也不把每張切片重新包裝成一張品牌海報。

切片前先規劃整份詳情的完整閱讀順序與資訊分配，再依語意安全切線輸出S版；上架切片不重新開始敘事，也不為每一片補品牌開場。提示詞中的商品不變項、風格、序列與來源是內部製作資訊，只有指定可見文字及必要實體印刷才呈現在圖上。

完整3版及S仍保留本商品全部不同的實質資訊，包括數值、條件、配件差異、操作及警語。可分配至功能頁、規格頁及說明頁，整併重複內容；不為大圖刪獨有資訊，也不為全量保留把每張主視覺排成密字文件。其他商品廣告、不販售SKU及活動不移入本商品成品，排除理由留存。MOMO編輯版的精簡另按專用規則。

## 3. 決定美術方向與閱讀節奏

選擇能服務本商品的色調、光線、照片質感、字體層級、留白與圖示語言，寫入摘要；沿用本次指定品牌與參考。可在內部比較方向後自行採用，不增加例行選稿關卡。

依[共用提示詞](redesign-prompts.md)保存本次「商品不變項」與「共同視覺設定」，兩段完整帶入每張獨立提示詞；原廠商品圖與已驗收風格anchor分開指定角色。單張改稿沿用共同設定，修改全套設定時檢查所有受影響圖片，不以同一版型代替視覺一致性。

- 情境主視覺給足商品與環境面積，用天空、地面、牆面或構圖留白承接文字。原廠已有好實拍，可重新裁構圖、延展環境及設計文字，無須為了改版全部重生。
- 主圖可用滿版／近滿版照片、分區大圖或細節主導構圖；詳情按任務變化。避免全套固定成「米白底＋頁眉細線＋小照片＋圓角資料卡」，使商品像文件插圖。
- 同套統一字體、層級、點色與照片語氣；景別、圖文比例及布局可變。戶外不固定軍綠／黑底，3C不固定霓虹。
- 直式詳情以連續敘事維持整套關係，中段不用重複品牌標頭當作識別手段；主題與內容要承接前後段落，切片後另檢查相鄰閱讀節奏。
- 短標題具體對應畫面，情緒標語輔助購買理由。品名與主要利益仍須清楚；不把「情境圖」「首屏」「商品賣點」等內部用詞印在成品。

## 4. 按畫面選製作方式，核對商品保真

商品身份、結構與販售內容必須正確。除非使用者要求原像素保留，不把所有重設計都限定成貼原圖；依本張任務選方式並如實記錄。

- 參考圖編輯／場景合成：情境或主視覺需要整合構圖、環境及光線時，按可用的imagegen技能與工具傳入已檢視的原廠商品圖。逐張重申輪廓、比例、零件數量、接點、材質、顏色、實體Logo與本SKU差異；新背景及合理光影可調，不能變成相似商品。只取來源能確認的角度，不補造背面、內部或零件。產物屬參考衍生畫面，放大逐項核對，不宣稱保留原始像素。
- 原商品區域合成／原照重構圖：精確接口、結構、標配、選項辨識或使用者要求原像素時，用高解析商品與細節區域保比例處理。新環境匹配視角、光向、尺度及接地；沒有適合視角就改場景，不能硬貼不合透視的商品。遵守環境的圖像編輯工具規則，不以簡陋腳本拼貼代替已要求的商業圖片設計。

模型改壞實體印刷、商標、型號、孔位等時，針對差異修正或改採原商品區域；無法核實則待審。文字擋住商品且無乾淨來源時，不臆測修出產品。生成工具沒有使用、沒有能力完成本次情境，或只完成原照排版時據實說明，不宣稱已生成新場景。

情境道具與非內含配件清楚區分，相關畫面附必要短註。帳篷的內外帳、天窗及延伸天幕，3C的接頭與相容裝置，依販售版本逐項核對。雨雪、火源、承重、快充或多設備供電畫面不能暗示無依據的性能；示意不偽裝成實測。參考作品只取視覺語言，不挪用其商品、Logo、促銷與數值。

## 5. 繁中排版參與整體設計

圖上文案先定稿並保存，使用繁體中文及台灣用語；數字、單位、大小寫、型號與條件不可自行變更。依內容選擇：

- 短標題、利益句及少量標籤：可由具文字能力的生圖工具整體設計字體、層級、留白與畫面關係，提示詞逐字列原文。生成後逐字核對，不因好看接受錯字。
- 規格表、密集小字、操作／安全資訊、需精確的品牌字樣：以真實字型及可控排版完成，或沿用正確來源區域。不要把長規格表交給模型猜字，也不要後貼整塊文件破壞構圖。
- 錯字修正：用可用編輯工具局部修正；同問題兩次仍失敗，改可控排字或把完整資訊移至適合的規格頁。無法完成則REVIEW。不用大色塊蓋未清乾淨的舊字。

可控文字工具不代表每張都由腳本從零排成同一模板；原生排字也不省略逐字驗收。兩種方式均須符合本張任務與整套美術方向。

## 6. 先驗證代表畫面，再展開整套

優先完成能驗證方向的代表圖，通常是主視覺與核心功能圖；有SKU差異或密集規格時再試該類版面。這是內部檢查，沿用入口直接交付或既有選稿約定，不新增使用者批准關卡。

實際檢視代表圖及後續每張成品，在摘要記錄具體觀察與修正。以下按可觀察條件判PASS／REVIEW，不以自評分數代替證據：

同時對照[相關合格／退稿案例](redesign-examples.md)判斷場景、賣點證據及SKU辨識，並按[整套一致性規則](redesign-prompts.md#4-生成與改稿時維持一致)比較總覽與單張；案例提供判斷依據，不取代實際商品及圖片驗收。

| 設計檢查 | 通過條件 |
|---|---|
| 商品與購買理由 | 封面約320px縮圖可辨商品與主要利益；其他圖主角、功能或SKU差異清楚，商品不被大字、裝飾及資料卡壓小。 |
| 情境與使用感受 | 場景、動作、尺度、接地與光影可信，能理解為何在此使用；露營氣氛來自營地生活，沒有誤導內含或性能。 |
| 賣點畫面證據 | 標題與畫面互相解釋，功能有對應細節／動作／已核實示意；沒有多張同角度全貌只換字與背景。 |
| 美感與閱讀節奏 | 大圖、文字、細節及規格比例適當，約375px閱讀寬度可讀；整套有一致識別與構圖變化，沒有文件式小照片堆卡或過度裝飾。直式詳情首尾品牌集中、中段不重複品牌開場，短主題承接上下文，相鄰切片閱讀順暢。 |
| 商品與內容一致 | SKU、結構、顏色、實體印刷、繁中、數值與限制逐項對照，完整資訊有成品去向。 |

要求新情境卻仍只有縮小原圖配資訊框、功能頁只有全貌配標題時，對應設計項不能PASS。先修正構圖、證據或製作方式再擴展。兩次仍無法解決依既有REVIEW規則說明；缺必要階段或產物為FAIL，機械稽核成功不代替設計品質。

## 7. 交接與追溯

重設計主圖、適用選項及完整3版重新執行[分割前視覺驗收](../../shopee-image-batch/references/pre-slice-review.md)，同時記錄上述設計檢查。全部必要條件通過後才產生S及明確要求的M；M編輯稿另行驗收，壓縮與改稿後重新核對。

沿用0_處理紀錄/重設計內容對照.csv，逐項記原文／摘要、定稿文案、來源檔與區域、保留／改寫／整併及理由、3版成品位置；重複表述指向承接位置。僅封面追溯採用資訊與必要購買條件，不把整套詳情塞進封面。

摘要及報告另記逐圖任務、美術依據、實際採用的商品參考與製作方式、背景／商品／文字生成或合成範圍、工具與提示詞、商品細節核對及設計驗收。參考圖編輯不冒稱原像素合成；未檢視的參考不當設計依據。

沿用命名、張數、尺寸、容量、浮水印及MOMO規則。兩套同做時各有成果根目錄、紀錄與驗收，不覆寫來源或既有版本。
